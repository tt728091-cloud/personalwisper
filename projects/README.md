# Project background for the to-do evaluator

Put a `<T3 project title>.md` file here (for example `my-app.md`) describing a T3 Code project in a few
paragraphs: what it is, its main parts, and the names you use for things. The local evaluator reads it as
background when it evaluates that project's to-do items. Without one it just works from your notes.

These files stay on your Mac: everything in this folder except this README is ignored by git.
